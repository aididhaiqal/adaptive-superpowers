# Adaptive Gate

- **Read-only:** inspect without artifacts. For bulky independent investigation, use one available read-only explorer via `references/explorer-handoff.md`; otherwise inspect locally. Keep coupled work here.
- **Fast path:** requires explicit acceptance; single-locus; maximum two production files plus tests; no resumed/compacted/concurrent/editing-delegated work; no blocking choice, security, destructive, production-data, migration, public-contract, cross-system, or external-state risk. After reading this gate, use three task phases: (1) inspect file contents/status; (2) implement and, when feasible, add runnable automated test file—transient checks do not count; (3) run fresh targeted verification; review the final diff against acceptance for omissions. Supported Critical/Important findings block completion. Material, evidence-backed recommendations stay optional/non-authorizing; never invent them. Remain in phase 3 while repairing failures. Announcement: sole pre-work update; do not restate acceptance.
- **Otherwise:** before implementation or consequential action, follow `references/full-router.md`.

Switch if scope/risk grows. Preserve user work; require destructive/external-action authority.
